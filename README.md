🍕 Domino's Pizza Sales – SQL Data Analysis Project
Project Overview
This project analyzes Domino's Pizza sales data using SQL for efficient data retrieval, transformation, and insight generation. The analysis focuses on sales performance, product popularity, and revenue trends to support strategic business decision-making.

Objectives

Retrieve and summarize order, sales, and product data directly from a relational database.

Identify key metrics: total orders, revenue, top-selling pizza types, popular pizza sizes, and hourly/daily order trends.

Calculate advanced business KPIs, such as revenue share by category and product, cumulative revenue over time, and category-based performance analysis.

Project Tasks

Data extraction via SQL queries, including multiple JOIN operations to combine pizza types, pizzas, orders, and order details.

Calculation of aggregate statistics (sums, averages, counts) and identification of best/worst-performing products.

Use of subqueries for advanced calculations like revenue share (%) and ranking mechanisms (e.g., top-3 pizza types by revenue).

Time-based analysis (orders by hour, daily sales averages).

Providing recommendations based on identified trends (top categories to focus on, optimal order times, inventory planning).

Tools & Techniques

SQL (aggregation, JOINs, subqueries, GROUP BY, ORDER BY, window functions if applicable)

Database management systems (e.g., MySQL, PostgreSQL, SQLite)

Optional: Data visualization libraries or dashboard tools for presenting results

Sample Questions Explored

What are the top 5 most ordered pizza types and their quantities?

Which pizza categories contribute the most to total revenue?

How do orders and sales trend over time (hourly, daily, cumulatively)?

Which sizes and categories are most popular with customers?

What is the revenue share percentage for each pizza category?

Outcome
Delivered a structured, scalable approach to pizza sales data analysis, with reusable SQL scripts enabling continuous and flexible business reporting.
